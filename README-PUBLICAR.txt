SITE SONIFIT - COMO PUBLICAR GRATUITAMENTE

1. Acesse https://github.com/new
2. Crie um repositório PUBLICO chamado sonifit-site (separado do repositório privado do app).
3. Envie apenas os arquivos index.html, privacidade.html, termos.html e style.css para a raiz desse novo repositório.
4. Em Settings > Pages > Build and deployment, selecione Deploy from a branch; branch main; pasta /(root); Save.
5. O endereco esperado, apos a publicacao, e:
   https://victorhenrique2.github.io/sonifit-site/
   https://victorhenrique2.github.io/sonifit-site/privacidade.html
   https://victorhenrique2.github.io/sonifit-site/termos.html
6. Confira se as paginas abrem e se o e-mail de contato e os dados da politica correspondem ao app real.

IMPORTANTE:
- Nao envie o projeto completo do aplicativo para o repositorio publico. Ele deve conter apenas os quatro arquivos do site.
- GitHub Pages no plano gratuito requer repositorio publico.
- A hospedagem gratuita nao garante aceitacao pelo Google OAuth. Para verificacao de marca, o Google normalmente pede um dominio que voce controle e consiga verificar via Search Console. github.io e um dominio compartilhado e pode nao atender esse requisito. Se o Google exigir essa verificacao, sera necessario obter um dominio proprio ou uma alternativa verificavel.
- A politica de privacidade precisa ser revisada ao atualizar o codigo, especialmente login, armazenamento de senhas, IA e compartilhamento de dados.
- O site nao cria backend nem habilita automaticamente o login Google no app.
